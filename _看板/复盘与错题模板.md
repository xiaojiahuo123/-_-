# 复盘与错题模板

> [!abstract] 用法
> 1. 错题本：把下面「错题本表头」粘进 [[错题本]]，一行一题，随时追加。
> 2. 日复盘：每晚 5 分钟，3 行。
> 3. 周复盘：每周轻课 90 分钟，填表 + 本周错题全重做。
> 4. 套卷复盘：按规划里的 120 分钟 SOP 走，只复盘**做错、蒙对、纠结超过 2 分钟**的题。

## 一、错因代码（统一用这 5 个）

| 代码 | 含义 | 典型表现 |
| :--: | :-- | :-- |
| **K** | 知识盲区 | 这个知识点/公式/词义根本没学过或忘了 |
| **S** | 审题偏差 | 看错问法、漏条件、被选项带偏 |
| **C** | 计算/操作失误 | 算错、抄错、涂错、单位错 |
| **T** | 时间不够 | 会做但没时间，或纠结太久 |
| **G** | 蒙猜 | 完全不会，纯靠感觉 |

> 每周统计代码分布：**K 多就回炉知识点，S 多就练审题，C 多就放慢 10 秒，T 多就调顺序和取舍。**

## 二、错题本表头（粘进 [[错题本]]）

```markdown
| 日期 | 模块/题型 | 题干关键词 | 我的答案 | 正确答案 | 错因 | 一句话教训 | 二刷 |
| :-- | :-- | :-- | :--: | :--: | :--: | :-- | :-- |
| 2026-11-22 | 资料/增长率 | 2025年某省GDP增速 | B | C | K | 增长率比较用「现期/基期-1」，别用增长量 | 11-29 ✅ |
```

- 只记 **❌ 错 / 🟡 蒙对 / 🐢 超时** 三类，其余不记。
- 「一句话教训」写**下次怎么做**，不抄解析（解析在例题笔记里，用链接回）。
- 每周日把本周错题重做一遍，二刷通过写 `日期 ✅`，仍错改写 `日期 ❌` 并保留。

## 五、行测套卷复盘（120 分钟 SOP）

| 时段 | 动作 | 产出 |
| :--: | :-- | :-- |
| 0-10min | 对答案，统计各模块对错、用时、超时模块 | 分数表一行 |
| 10-50min | 错题 + 蒙对 + 纠结题 **不看解析重做** | 通过/仍错 |
| 50-85min | 看解析，逐题填错因 + 一句话教训 | 错题本 |
| 85-110min | 策略复盘：顺序、取舍、哪题该跳、时间丢在哪 | 3 条教训 |
| 110-120min | 更新趋势表，定下周 2 个补漏点 | 下周计划 |

```markdown
### 行测套卷复盘 第__套（2026-MM-DD）
- 总分：__ / 100　用时：__ min　超时模块：____
- 各模块：言语__/__ 判断__/__ 资料__/__ 数量__/__ 政治常识__/__
- 错题重做（不看解析）通过：__ / __
- 错因分布：K__ S__ C__ T__ G__
- 策略问题（顺序/取舍/时间）：
- 三条可执行教训：
  1.
  2.
  3.
- 下周补漏 2 个点：
```

## 六、申论复盘（90 分钟 SOP）

| 时段 | 动作 |
| :--: | :-- |
| 0-20min | 逐条对标参考答案：漏了哪些要点、多了哪些废话 |
| 20-40min | 重写 1 道小题，或大作文的 1 个分论点段 |
| 40-60min | 抄 3 条更好的表述（自己的话 vs 参考答案的差距） |
| 60-90min | 归因：是**找点**问题，还是**结构/表达**问题？写进下周重点 |

```markdown
### 申论复盘 2026-MM-DD（题目：____）
- 自评：找点__ / 结构__ / 表达__ / 字数__
- 漏掉的要点：
- 多余的要点：
- 3 条更好的表述：
  1.
  2.
  3.
- 归因：找点 / 结构 / 表达 / 时间
- 重写计划：__ 月 __ 日重写第 __ 题
```

## 七、分数趋势表（每套一行，冲刺激励用）

```markdown
| 日期 | 套卷 | 言语 | 判断 | 资料 | 数量 | 政治/常识 | 总分 | 用时 |
| :-- | :-- | :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| 2027-02-14 | 行测第 1 套 |  |  |  |  |  |  |  |
```

## 八、三条原则

1. **只复盘该复盘的题**：错、蒙、慢。全对题和纯蒙题扫一眼就过。
2. **写「下次动作」，不抄解析**：解析已经在例题笔记里，复盘只提炼方法。
3. **7 天内必须重做**：当天记 → 当周重做 → 考前第 3 轮。不复做的错题本等于没记。
